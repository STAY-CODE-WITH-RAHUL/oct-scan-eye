# VISION AI PRO - Deep Retinal Diagnostic Engine

## Overview

VISION AI PRO is an AI-powered retinal disease detection system developed using Streamlit, TensorFlow, MobileNetV2, OpenCV, and Grad-CAM visualization. The application analyzes Retinal OCT (Optical Coherence Tomography) scans and predicts possible retinal conditions using a deep learning model.

The system provides:

* Automated disease classification
* Prediction confidence scores
* Grad-CAM pathology heatmaps
* Clinical interpretation reports
* Management recommendations
* Modern premium dashboard interface

---

## Features

### Disease Detection

The model classifies retinal OCT images into the following categories:

1. CNV (Choroidal Neovascularization)
2. DME (Diabetic Macular Edema)
3. DRUSEN
4. NORMAL

### AI Analysis Dashboard

* Original OCT image display
* Disease prediction with confidence score
* Neural distribution probabilities
* Clinical evaluation report
* Risk level assessment

### Explainable AI

Grad-CAM heatmaps highlight the retinal regions that influence the model's decision, improving transparency and interpretability.

### Clinical Recommendations

For each detected condition, the system generates:

* Disease explanation
* Risk category
* Suggested management protocol
* Follow-up recommendations

## Disease Categories

### CNV

Choroidal Neovascularization involves abnormal blood vessel growth beneath the retina and may lead to severe vision impairment.

### DME

Diabetic Macular Edema results from fluid accumulation in the macula due to diabetic retinal complications.

### DRUSEN

Drusen are yellow deposits beneath the retina and are commonly associated with age-related macular degeneration.

### NORMAL

No significant retinal abnormalities detected.

## Explainability

The system uses Gradient-weighted Class Activation Mapping (Grad-CAM) to visualize regions that contribute most to the prediction.

Benefits:

* Improved transparency
* Better clinical interpretability
* Enhanced trust in AI predictions
